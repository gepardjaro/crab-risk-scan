# CRAB — Code Risk Analysis Bot

**The open-source security scanner with claws.**

CRAB brings source-code checks, dependency advisories and a software bill of materials (SBOM) into one local CLI. It ranks findings by severity, removes repeated observations and preserves their origin. The SBOM is a separate CycloneDX JSON document generated by Syft from a repository snapshot.

## Quick start

Use Python 3.10 or newer. From this checkout:

```sh
python -m pip install .
crab-risk-scan scan examples/demo
crab-risk-scan collect examples/demo --trivy examples/trivy-fs.json
```

The first command after installation reports two medium findings. The second adds a synthetic high-severity dependency advisory and ranks it first. Both exit 1. The source checkout also supports `python -m crab_risk_scan` in place of the installed command. For scanning another checkout, run the installed command from a trusted working directory.

| Command | Output | Exit status |
|---|---|---|
| `scan DIRECTORY` | Original v1 JSON report covering the built-in Python TLS and Dockerfile USER checks | 0 clean within measured coverage, 1 findings, 2 incomplete |
| `collect DIRECTORY [--trivy FILE ...]` | v2 JSON report. Repeat the flag for each Trivy filesystem language-package report from the same snapshot. Includes normalized severity, origin, fingerprints and import counts. | 0 clean, 1 findings, 2 incomplete |
| `sbom DIRECTORY [--output FILE]` | A CycloneDX JSON inventory produced by an installed Syft CLI. Defaults to stdout. | 0 inventory generated, 2 failure |

### Generate an SBOM

Install [Anchore Syft](https://github.com/anchore/syft) on the scanner host. CRAB discovers Syft on the trusted executable path or accepts `--syft /absolute/path/to/syft`. Run:

```sh
crab-risk-scan sbom examples/inventory --output demo.cdx.json
```

The example lockfile contains `crab-demo-leaf@1.0.0`. It appears in the inventory without an advisory or a package installation. For your own repository, replace `examples/inventory` with the checkout path. Catalog coverage depends on what the checkout contains. The CI job generates this example SBOM and publishes it as a workflow artifact.

### Import dependency findings

With Trivy installed, generate a dependency report for the snapshot and pass it to CRAB. Keep generated files outside the scanned tree.

```sh
trivy fs --scanners vuln --pkg-types library --format json --output deps.json /path/to/checkout
crab-risk-scan collect /path/to/checkout --trivy deps.json
```

## The CRAB ecosystem

| Feature | Name | Implemented or planned |
|---|---|---|
| SAST | Claws | Built-in Python TLS check. Bandit and Opengrep adapters planned. |
| SCA and SBOM | Shell | Imports Trivy dependency findings. Generates CycloneDX inventories with Syft. |
| Secrets | Sniffer | Gitleaks report adapter planned. |
| IaC | Burrow | Built-in final-stage Dockerfile USER check. Checkov Terraform and Kubernetes adapters planned. |
| Container security | Exoskeleton | Trivy image package findings and digest-based correlation planned. |
| Rule engine | Pinch | Built-in rule dispatch. Versioned rule packs and dialect-specific rules planned. |
| Reporting | Crab Trap | Unified JSON, exact deduplication and severity ordering. Cross-engine correlation and SARIF planned. |
