# Naming review

Reviewed on 20 November 2026. The public identity is **CRAB — Code Risk Analysis Bot**. Use **crab-risk-scan** for the repository, Python distribution and terminal command, and **crab_risk_scan** for the import package. The tagline is “The open-source security scanner with claws.”

| Name checked | Evidence | Decision |
|---|---|---|
| Crab | SeaHorn's Crab is a static-analysis library. PyPI's crab is a cron monitoring package. | Use the expanded product name in headings and the qualified command in examples. |
| CRAB-Runner | An existing Rust security project uses Crab-Runner. | Avoid this identifier on GitHub and in packaging. |
| CodeCrab | A local code-review product already uses this adjacent name. | Retain the CRAB acronym and its own spelling. |
| CRAB RISK SCAN / Code Risk Analysis Bot | Finland's PRH basic search returned 0 results for each string. Searching CRAB returned HOLY CRAB, T202351994. The GitHub repository search for crab-risk-scan in the name returned no matches before creation. | Adopt the qualified name for this repository. PyPI registration and exclusivity are unverified. |

The PRH query covers national filings and international registrations designating Finland. EU marks are also relevant. No EU-wide, US or other international similarity clearance was completed. Existing project names indicate practical confusion risk. A legal infringement finding would require additional facts about the mark, territory and relevant goods or services.

Use Claws, Shell, Sniffer, Burrow, Exoskeleton, Pinch and Crab Trap as CRAB feature names. Only the top-level CLI and distribution need a public namespace in this release.
